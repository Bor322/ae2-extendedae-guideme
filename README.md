- AppliedEnergistics/Applied-Energistics-2 branch `1.21.1`
- GlodBlock/ExtendedAE branch `1.21.1-neoforge`

`pack_format` 34. Do not unzip. Put the zip in `resourcepacks` and enable it.

The binary zip cannot be committed through the text-only GitHub contents API. After you have the file locally:
